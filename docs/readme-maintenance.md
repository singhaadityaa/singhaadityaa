# README maintenance

The profile README is the public-facing entry point for this repository.

## Keep it focused

- Lead with current work and active systems.
- Remove stale claims instead of accumulating historical copy.
- Prefer short explanatory sections over badge walls.
- Keep links canonical and verify them after edits.
- Preserve accessible alt text for visual assets.

## Review checklist

Before merging a README change, check the rendered profile on desktop and mobile-width layouts and verify that tables and images remain readable.
