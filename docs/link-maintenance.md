# Link maintenance

The profile README intentionally uses a small set of canonical links.

When updating them:

1. Prefer the primary `https://allesclinx.com/` destination over campaign or redirect URLs.
2. Keep GitHub organization links pointed at `https://github.com/alles-clinx`.
3. Remove links when a destination is retired rather than leaving broken references.
4. Check both the rendered README and raw Markdown after changes.
